| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Type         | Managed RDBMS                                                                                                                                                                                                                                                                                                                                                      | Fully-managed NoSQL (no setup, admin work needed)                                                                                                                                                                                      |
| Storage      | 64 TB for Aurora, 16 TB otherwise                                                                                                                                                                                                                                                                                                                                  | Virtually unlimited                                                                                                                                                                                                                    |
| Performance  | General purpose storage is an SSD-backed storage option that delivers a consistent baseline of 3 IOPS per provisioned GB with the ability to burst up to 3000 IOPS.<br><br>Provisioned IOPS storage is an SSD-backed storage option designed to deliver a consistent IOPS rate that you specify when creating a database instance, up to 40,000 IOPS per database. | Sub-ms R/W performance, can handle more than 10 trillion requests per day with peaks greater than 20 million requests per second. Petabytes of storage. IT IS A BEAST!<br><br>DAX is cache for DynamoDB that can improve reads by 10x. |
| Availability | Multi-AZ deployments synchronously replicates your data to a standby instance in a different AZ.<br><br>RDS will automatically switch over to standby in time of failure.                                                                                                                                                                                          | Default replication across three AZs                                                                                                                                                                                                   |
| Scalability  | 5 replicas in regular RDS and up to 15 in Aurora, manual scaling                                                                                                                                                                                                                                                                                                   | Unlimited capacity, AUTOMATIC infinite horizontal scaling                                                                                                                                                                              |
| Uses         | Traditional, ERP, CRM etc                                                                                                                                                                                                                                                                                                                                          | Internet-scale apps like gaming, mobile etc                                                                                                                                                                                            |
